# IBM Applied Data Science Capstone

## Predicting Falcon 9 First-Stage Landing Success

This repository contains my completed IBM Applied Data Science Capstone Project.

The project analyzes Falcon 9 launch data and predicts first-stage landing success using data collection, data wrangling, exploratory data analysis, SQL, interactive visualization, and machine learning.

## Files

- `space-x-api-lab.ipynb` — SpaceX API data collection
- `space-x-web-scraping.ipynb` — Web scraping
- `data-wrangling-lab.ipynb` — Data wrangling
- `eda-viz-lab.ipynb` — Exploratory data visualization
- `eda-sql-lab.ipynb` — SQL analysis
- `folium-lab.ipynb` — Folium geographic analysis
- `plotly-dash.py` — Plotly Dash dashboard
- `predictive-analysis-lab.ipynb` — Machine learning

## Machine Learning

Models evaluated:

- Logistic Regression
- Support Vector Machine
- Decision Tree
- K-Nearest Neighbors
